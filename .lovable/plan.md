

## صفحة سجل الاعتمادات التلقائية `/admin/auto-approval-log`

### الهدف
صفحة تدقيق مخصصة للإدمن تعرض جميع الطلبات التي اعتمدها النظام تلقائياً (`auto_approval_log`)، مع كل البيانات الحساسة المستخرجة من السند، لمراجعة سريعة وكشف أي اختلالات.

### تصميم الصفحة

```text
┌──────────────────────────────────────────────────┐
│ ⚡ سجل الاعتمادات التلقائية                       │
│ مراجعة كل الطلبات التي اعتمدها النظام تلقائياً  │
└──────────────────────────────────────────────────┘

┌─ ملخص ──────────┬──────────────┬──────────────┐
│ الإجمالي: 42    │ اليوم: 5     │ آخر 7 أيام:18│
└─────────────────┴──────────────┴──────────────┘

[🔍 بحث (اسم، مبلغ، هاش)]   [📅 من → إلى]   [↻]

┌──────────────────────────────────────────────────┐
│ التاريخ │ الطالب │ المبلغ │ المستخرج │ المستلم │ │
│         │        │ متوقع/ │  من سند  │ تطابق؟ │ │
│         │        │ مستخرج │          │         │ │
├─────────┼────────┼────────┼──────────┼─────────┤
│ 20/4    │ أحمد… │ 5000/  │ علي محمد │ ✅ نعم  │ │
│ 14:23   │        │ 5000   │          │         │ │
│         │ [👁 عرض السند] [🔗 فتح الطلب]         │ │
├─────────┼────────┼────────┼──────────┼─────────┤
│  ...    │        │        │          │         │ │
└──────────────────────────────────────────────────┘
```

عند النقر على صف → يفتح Drawer/Dialog يعرض كل الحقول (hash، sender، fraud_status، تاريخ الجدولة، رابط طلب الدفع الأصلي).

### قواعد الوصول
- مسار محمي للإدمن فقط: `useAuth("admin")` + redirect إذا لم يكن أدمن.
- البيانات تُجلب من جدول `auto_approval_log` (RLS الحالي يسمح للأدمن فقط بالقراءة — جاهز).
- ربط مع `payment_requests` و `students` لجلب اسم الطالب وحالة الطلب الحالية.

### تفاصيل تقنية

**ملفات جديدة**:
1. `src/pages/admin/AdminAutoApprovalLog.tsx` — الصفحة الرئيسية
   - استعلام Supabase: `auto_approval_log` LEFT JOIN على `payment_requests` (للحصول على status الحالي) و على `students` (لاسم الطالب عبر user_id).
   - فلاتر: نطاق تاريخ + بحث نصي على (extracted_recipient، extracted_sender، receipt_hash، اسم الطالب).
   - بطاقات إحصائية أعلى الصفحة: إجمالي، اليوم، آخر 7 أيام، إجمالي المبالغ.
   - جدول باستخدام `Table` من shadcn مع pagination كل 25 صف.
   - زر "عرض السند" يفتح `receipt_url` من `payment_requests` في تبويب جديد.
   - زر "فتح الطلب" يوجه إلى `/admin/payments?id={payment_request_id}`.
   - استخدام React Query مع `staleTime: 30s` (وفقاً لـ data-freshness-strategy).

**ملفات معدّلة**:
2. `src/App.tsx` — إضافة المسار:
   ```tsx
   <Route path="/admin/auto-approval-log" element={<AdminAutoApprovalLog />} />
   ```
3. `src/pages/admin/AdminDashboard.tsx` (أو الـ Sidebar) — إضافة بطاقة/رابط "سجل الاعتمادات التلقائية" مع أيقونة `Zap` تحت قسم "المدفوعات".

**اعتبارات أمان واتساق**:
- لا حاجة لـ migration: الجدول والسياسات موجودة بالفعل.
- استبعاد admins/moderators من قائمة الطلاب لا ينطبق هنا (الـlog يخص الطلاب فقط).
- استخدام `format` من `date-fns` بـ locale `ar` لعرض التواريخ.
- شارة لونية: `recipient_match=true` ✅ أخضر، `false` ⚠️ أصفر، `null` رمادي.
- إذا كانت `payment_requests.status` تغيرت لاحقاً إلى `rejected` (إلغاء يدوي بعد الاعتماد) → عرض شارة "أُلغي لاحقاً" 🔴 لإبراز أي تجاوز اكتشف لاحقاً.

**توافق الموبايل**:
- الجدول داخل `overflow-x-auto` للشاشات الصغيرة.
- استخدام `PageShell` و `pb-bottom-nav` (لكن هذه صفحة admin، لا bottom nav للأدمن).

### النتيجة
صفحة تدقيق احترافية واحدة تتيح للأدمن مراجعة كل الاعتمادات التلقائية في ثوانٍ، مع روابط مباشرة للسند الأصلي وطلب الدفع للتحقق العميق عند الحاجة.
